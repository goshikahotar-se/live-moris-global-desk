# Moris Global Desk
A simple web app for Mauritians working with global teams — compare Mauritius time with other countries and see the hour difference at a glance.

Live app: https://live-moris-global-desk.onrender.com/

# Phase 1 (current)
 - Mauritius current time
 - United Kingdom current time (default)
 - Message showing how many hours Mauritius is ahead of UK time
 - Dark-themed UI

# Tech stack
 - ASP.NET Core Razor Pages
 - .NET 10
 - Docker
 - Hosted on Render (free tier)

# Run locally
```
cd MorisGlobalDesk
dotnet run --project MorisGlobalDesk
```
